## Find work without scrolling

- Each mode now has its own compact search button in the list header.
- Implement searches tasks, Conversation searches chats, and Architect searches plans.
- Search stays out of the way until opened and does not add a permanent toolbar row.

## Drafts survive interruptions

- Unsent composer text, pasted images, and context references now survive navigation and application restarts.
- Drafts stay isolated to their task or conversation, so switching work cannot mix content between sessions.
- Macro clears a draft only after the message send succeeds. Failed sends keep the content ready for another attempt.

## Clearer task startup

- The first message of a standalone task now appears immediately while Macro prepares the task behind it.
- A compact progress card reports naming, workspace creation, project preparation, and agent startup as they happen.
- The central view no longer pretends a project is empty while its initial state is still loading.

## More reliable projects and browser sessions

- Project creation and Architect startup now serialize the work that must not overlap, with bounded waits instead of silent stalls.
- Browser runtime clients keep explicit ownership of their session while handoffs and RPC calls are in flight.
- Late asynchronous results can no longer replace newer task, project, or runtime state.

## Safer Git recovery

- Review snapshots now stay bound to the exact task, project, checkpoint, and repository state that created them.
- Macro rejects stale recovery requests and hides external Git paths that do not belong in the review.
- Direct project checkpoints use bounded capture and restoration rules, with clearer failures when their state is missing or damaged.

## Windows installer fixes

- New per-user installs default to the standard local Programs folder for Macro.
- Existing valid install locations remain available during upgrades.
- Temporary installer test paths and stale registry values no longer become the proposed destination.
