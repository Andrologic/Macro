# Archive Documentation

Ce dossier contient un historique documentaire minimal. Il n'est pas normatif et ne fait plus partie de la documentation de reference active.

Les seules sources de verite a utiliser en priorite sont :

- `docs/functional-spec.md`
- `docs/technical-architecture.md`
- `docs/roadmap.md`

## Documents conserves

Aucun document produit historique n'est conserve ici. Les anciennes hypotheses
sur des capacites futures ont ete retirees pour eviter qu'elles soient lues
comme des capacites de la ligne 0.1.

## Documents retires

Les documents suivants ont ete retires de l'archive minimale :

- ancienne specification API mobile et backend remote, trop volumineuse et trop contractuelle pour l'etat 0.1 du produit
- anciens apercus produit et workflows redondants avec la specification fonctionnelle
- anciens plans d'implementation frontend et backend devenus obsoletes
- anciennes TODO lists techniques et documentations IPC depassees

Tout contenu encore utile doit etre resume dans les documents actifs ou, a defaut, dans cet index plutot que conserve sous forme de doublon.
