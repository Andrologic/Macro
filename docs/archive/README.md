# Archive Documentation

Ce dossier contient les anciens documents de travail, de planification ou de specification qui ne constituent plus la documentation de reference active.

Les documents vivants a utiliser en priorite sont :

- `docs/functional-spec.md`
- `docs/technical-architecture.md`
- `docs/roadmap.md`

Les fichiers archives sont conserves temporairement pour :

- retrouver d'anciennes hypotheses
- verifier l'origine de certaines decisions
- recuperer ponctuellement des idees ou du contexte historique

Ils ne doivent plus etre consideres comme source de verite.
