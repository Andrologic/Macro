# Utiliser Macro

Commencez par [Premiers pas avec Macro](getting-started.md). Vous y connecterez
un fournisseur d'IA, ajouterez un projet et réaliserez une petite modification
jusqu'à sa validation et son intégration locale.

## Quelques repères

| Terme | À quoi il sert |
| --- | --- |
| Projet | Le dossier sur lequel vous travaillez, avec son dépôt Git pour ce guide |
| Groupe | Plusieurs projets réunis pour travailler sur un même produit |
| Chat | Échanger avec un agent et explorer un sujet |
| Architect | Préparer un plan et sa stratégie pour un travail qui demande plusieurs tâches |
| Implement | Exécuter les tâches et examiner leurs changements |
| Worktree | Un dossier de travail lié au dépôt Git, avec une branche propre à la tâche |

## Guides disponibles

- [Premiers pas avec Macro](getting-started.md).

Les prochains guides pourront détailler Architect, le travail sur plusieurs
projets, les réglages et la résolution des blocages Git. Ils seront ajoutés ici
une fois rédigés et vérifiés.
