# Utiliser Macro

Commencez par [Premiers pas avec Macro](getting-started.md). Vous y connecterez
un fournisseur d’IA, créerez un système AgSDL dans un projet d’essai et suivrez son exécution.

## Quelques repères

| Terme | À quoi il sert |
| --- | --- |
| Projet | Retrouver les systèmes créés dans le même contexte |
| Architect | Concevoir un système, inspecter son graphe et enregistrer sa définition |
| Operate | Suivre une exécution et consulter les échanges de ses agents |
| Chat | Échanger librement avec un agent |
